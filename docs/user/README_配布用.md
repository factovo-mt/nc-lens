# NC Lens 利用ガイド

NC Lens は、NC プログラムのカスタムマクロと四則演算を展開する Windows アプリです。展開結果、変数の変化、エラーを元の行と照合し、工具経路を確認できます。同じ機能の Web 版（https://nclens.factovo-works.com）もあります。

## 動作環境

- Windows 10 / 11（x64）
- Microsoft Edge WebView2 Runtime
- Web 版：最新の主要なブラウザ（スマートフォン・タブレットを含む）

## インストールと削除

1. ZIPを展開し、末尾が `-setup.exe` のインストーラを実行します。
2. 画面の案内に従ってインストールし、スタートメニューから「NC Lens」を開きます。
3. 削除するには、Windowsの「設定」→「アプリ」から「NC Lens」を選び、アンインストールします。

WebView2が無い場合、インストーラがWebView2をダウンロードします。ダウンロードにはインターネット接続が必要です。設定や自分で保存したファイルは、必要に応じてバックアップしてください。

## ポータブル版

1. ZIPを展開し、`portable`フォルダを自分が書き込める場所に置きます。
2. WebView2を導入済みのPCで`nclens.exe`を開きます。
3. 設定を別のPCに移す場合は、アプリを閉じ、exeと同じ場所にできた`nclens.settings.json`をexeと一緒にコピーします。JSONに記録されたポストのパスなどは、移動先で開き直してください。

exeのフォルダに書き込めない場合の保存先は`%APPDATA%\NC Lens\nclens.settings.json`です。アプリ設定の「ファイル」から実際の保存場所を確認できます。ポータブル版を削除するには、アプリを閉じてフォルダを削除します。

## 主な操作

| 操作 | 内容 |
| --- | --- |
| Ctrl+O | NCファイルを開く（.nc・.min・.ncd・.txt。解析・展開は自動。編集・設定の変更でも自動で更新） |
| Ctrl+N | 新規（保存の既定名は `無題.nc`） |
| Space、F5 | 再生・一時停止 |
| Ctrl+S | 編集したNCファイルを上書き保存する。展開結果の保存の既定名は `<名前>_展開.nc` |
| 展開結果・変数の追跡・エラー | 行を選ぶと元のNCの該当行を強調する |
| XY・YZ・XZ・3D、4分割 | 視点と表示数を切り替える。ホイールで拡大・縮小、Homeで全体を表示 |
| 再生ボタン | 工具経路の再生・逆再生・一時停止とブロック単位の移動 |
| モーダルパネル | カーソルや再生位置に対応するGコード、送り、座標などを確認 |
| Ctrl+R | 距離・推定時間・座標範囲などのレポートを開く。JSON保存に対応 |
| 設定メニュー | ポスト・コード定義（ポストとニーモニック・固有のセット）、アプリ設定（テーマ・表示など） |
| コードにマウスを重ねる | コードの説明のツールチップ。Ctrl を押す間は全文 |
| ヘルプメニュー | 主な機能・キー操作・マクロ一覧・リンク・変更履歴 |

## 設定ファイル

| ファイル | 内容 |
| --- | --- |
| `.post.toml` / `.json` | 機械条件と展開設定。配布物の`default.post.toml`を「設定」→「ポスト・コード定義」から開けます |
| `.dialect.toml` / `.json` | ニーモニック・固有：G・Mコード、アドレス、マクロ構文、マクロ記号の定義。配布物にFANUCとOSPの定義を同梱 |
| `nclens.settings.json` | ウィンドウや画面表示、最近使ったファイル、登録したニーモニック・固有など。共有前にファイルのパスを確認してください |

### 同じブロックの重複指定

- ポストの `[codes]` で、軸などの同じアドレスは `duplicate_word`、同じモーダル群の G コードは `duplicate_g_group` を設定します。`last`（既定）は最後、`first` は最初を採用し、`error` はそのブロックを実行しません。
- `warn_on_duplicate`（既定は `true`）で重複の警告を切り替えます。展開出力には採用したワードが入ります。
- M コードは `duplicate_m` の `all`（既定）、`first`、`last` で選択します。`max_m_per_block`（既定は 3）の超過は警告になります。
- G65 の同じ引数は `duplicate_word` に従います。引数指定 II の I・J・K は組ごとに別の変数に渡します。
- 重複時の扱いは制御装置と機械の設定によって異なります。機械のプログラミング説明書とパラメータ説明書で確認してください。

## スマートフォン・狭い幅の配置

- スマートフォン：上に描画、下のパネルをタブで切り替え（NC・展開結果・使用コード・集計・モーダル・変数の追跡）。上の ☰ でメニュー
- 描画とパネルの境界のドラッグで描画の大きさを変更。横向きは左に描画、右にパネル
- Windows 版もウィンドウの幅で同じ配置。アプリ設定 → 表示 → 狭い幅の配置で『常に通常の配置』も選択可

## プライバシー

- アクセス解析：Cloudflare Web Analytics（Web 版の公開用のみ）
- Cookie 不使用、個人の特定なし
- 集計の対象：訪問数・閲覧ページ・参照元・国・端末の種類
- 開いた NC の内容は送信しない（ブラウザ内で処理）
- Windows 版は通信なし（リンクを開く操作を除く）
